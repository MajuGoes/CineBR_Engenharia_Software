# 📌 Sobre o Projeto

O CineBR é uma aplicação web desenvolvida com o objetivo de modernizar o processo de compra de ingressos de cinema, permitindo que clientes realizem compras online de forma prática, rápida e segura. Além disso, o sistema oferece funcionalidades administrativas para gerenciamento de filmes, sessões, salas e relatórios gerenciais.

O projeto foi desenvolvido com foco em organização, segurança, experiência do usuário e escalabilidade.

---

# 📌 Objetivos do Projeto

- Facilitar a compra online de ingressos
- Reduzir filas e desistências presenciais
- Melhorar o gerenciamento administrativo do cinema
- Disponibilizar relatórios estratégicos de vendas
- Garantir maior organização das sessões e assentos

---

# 🧩 Componentes do Sistema

## 👤 Usuário
Responsável pelo gerenciamento dos clientes cadastrados no sistema, incluindo autenticação, permissões e histórico de compras.

---

## 🎥 Filme
Gerencia as informações dos filmes disponíveis para exibição, como:
- nome
- gênero
- duração
- classificação indicativa
- sinopse

---

## 🏢 Sala
Responsável pelo controle das salas de exibição, incluindo:
- número da sala
- capacidade
- tipo da sala

---

## 💺 Assento
Controla os assentos disponíveis em cada sala de cinema.

---

## 🕒 Sessão
Gerencia as sessões de exibição dos filmes, contendo:
- horário
- filme relacionado
- sala
- tipo de exibição

---

## 🛒 Compra
Representa o processo de compra realizado pelo cliente.

---

## 💳 Pagamento
Gerencia os pagamentos realizados no sistema, incluindo:
- status
- valor
- forma de pagamento
- token de segurança

---

## 🎟️ Ingresso
Responsável pela emissão do ingresso em formato QR Code após a confirmação do pagamento.

---

## ⭐ Avaliação
Permite que clientes avaliem filmes assistidos utilizando notas de 1 a 5 estrelas.
